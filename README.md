# 이야기 · MUD

퇴마요새용 Windows x64 독립 클라이언트입니다. 이야기멀티 원본을 수정하거나 포함하지 않습니다.

현재 버전: **0.3** · [버전별 변경점](CHANGELOG.md) · [전체 작업 현황과 구조](docs/project-status.md) · [혼잣말 사용 안내](docs/monologue-guide.md)

저장소에는 소스와 문서가 포함됩니다. 새로 clone한 환경에서는 아래 개발 절차로 빌드하세요.

## 실행

Windows 배포 ZIP을 모두 풀고 `Iyagi Mud.exe`를 실행하세요. ZIP을 만드는 방법과 배포 절차는 [Windows 배포 안내](docs/distribution.md)를 참고하세요. 소스에서 개발할 때는 `npm run build` 후 `npm start`로 실행할 수 있습니다.

상단 **접속 → 서버 연결 → 퇴마요새**를 선택하면 `xmud.ddnsfree.com:6666`에 CP949로 접속합니다. **접속 → 프로필 관리**에서 서버 이름, 주소, 포트, 인코딩을 추가하거나 수정할 수 있습니다. 앱 버전은 왼쪽 앱 이름 아래와 **도움말 → 이야기 정보**에 표시됩니다.

서버가 안내하는 대로 명령 입력창에서 로그인하세요. 계정과 비밀번호는 저장하지 않습니다. 비밀번호를 입력하기 전에 **비밀 입력**을 켜고 입력 완료 후 끄세요. 서버의 Telnet ECHO 협상도 비밀 모드에 반영됩니다. 서버가 비밀번호 상태를 알리지 않는 경우 수동 전환이 필요합니다.

## 기본 사용

- 화면의 일반 영역을 클릭하면 채팅 입력창에 포커스가 이동합니다. 텍스트 드래그 선택과 다른 입력칸·버튼 조작은 유지합니다.
- **환경 설정 → 화면·전송 → 채팅 입력창 위치**에서 출력창 위/아래를 선택하고 저장하세요. 재실행 후에도 유지됩니다.
- 채팅 입력창에서 Enter로 전송. ↑/↓로 세션 명령 기록을 탐색합니다.
- `보기|상태`는 두 명령을 순서대로 전송합니다. 기본 간격 150ms.
- `보기|$,상태`는 추가 지연을 둡니다. $, 기본 500ms, 설정에서 변경 가능.
- `$$`는 달러 문자 하나를 보냅니다. 비밀 입력에서는 매크로 문법을 해석하지 않습니다.
- 환경 설정에서 단축버튼 10개와 A1~A10 / S1~S10 매크로를 편집합니다.
- 기본 키는 Alt+F1~F10 / Shift+F1~F10. `$A1`, `$S1`로 참조합니다. 키 칸에서 다른 조합을 눌러 재지정하거나 Backspace로 기본값을 복원합니다. OS 예약 키는 운영체제가 먼저 처리할 수 있습니다.
- 자동반응은 정확한 문자열 일치이며 정규식을 지원하지 않습니다. 규칙 편집 후 왼쪽 토글을 켜세요. 연결 해제·설정 저장·비밀 입력 진입 시 꺼집니다.
- **모든 자동 전송 중지**로 대기 명령과 자동반응을 중지합니다. 이미 전송된 명령은 취소할 수 없습니다.
- F8 환경 설정, F11 전체화면. 터미널 선택 후 Ctrl+Shift+C로 복사.
- ALIAS.TXT 가져오기는 CP949 텍스트, 최대 150개 문장입니다. 자동 명령 치환과 다릅니다.
- 갈무리는 수신 텍스트를 UTF-8로 저장하며 ANSI 제어 코드가 포함될 수 있습니다. 비밀 입력 중 기록을 멈춥니다. 서버가 나중에 다시 출력하는 민감한 내용까지 자동 판별하지는 않습니다.

## 혼잣말 (v0.2)

상단 **혼잣말**에서 SCS를 불러와 **번역**한 다음 **실행**하세요. 필요한 사용자 헤더 폴더를 선택할 수 있습니다. 번역만으로 서버에 명령을 보내지는 않습니다. 실행은 연결 후 가능하며 실제 명령을 전송합니다. 사용법과 호환 범위는 [혼잣말 안내](docs/monologue-guide.md)를 참고하세요.

## 저장 위치

설정은 Electron 사용자 데이터 폴더의 `settings.json`에 저장됩니다(일반적으로 `%APPDATA%/iyagi-mud`). 저장 전 `.bak` 백업을 만듭니다. 손상된 파일은 시작 시 덮어쓰지 않고 기본값으로 시작합니다. 설정을 저장하면 기존 파일이 백업으로 남습니다. 명령 기록은 메모리에만 존재하며 연결 종료 시 비워집니다.

## 원본과의 차이

독립 구현이며 원본 프로그램의 모든 기능을 복제하지 않습니다. `.MAC`/`.ANS` 바이너리 가져오기, 화면 좌표 조건, 파일 전송, 여러 동시 세션은 미지원입니다. 매크로 참조는 명령 경계로 확장합니다. 원본 $, 지연의 정확한 시간은 미확인이므로 사용자 설정으로 제공합니다. 현재 앱은 코드 서명이 없는 폴더형 배포입니다.

## 개발

Node.js 22.12 이상과 npm이 필요합니다.

```powershell
npm ci
npm test
npm run check
npm run build
npm start
npm run pack -- --config.directories.output=release-v0.3.0
node scripts/ui-test.mjs
node scripts/smoke.mjs
```

이 작업 환경에는 npm이 없어 `.tools/package/bin/npm-cli.js`를 설치해 사용했습니다. 같은 환경에서는 `npm` 대신 `node .tools/package/bin/npm-cli.js`를 사용하세요. 네트워크가 제한된 실행 환경에서는 TCP 테스트와 의존성 다운로드에 네트워크 권한이 필요합니다.

Electron 45.2.3의 이 환경용 설치 과정에서 압축 해제 네이티브 바인딩 누락이 발생했습니다. 빌더는 정상 다운로드·패키징했고 개발용 런타임은 같은 버전의 캐시 ZIP을 `node_modules/electron/dist`에 풀어 복구했습니다. 이미 만들어진 배포 폴더 실행에는 개발 도구가 필요하지 않습니다.

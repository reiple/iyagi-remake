# 혼잣말 구현 및 검증 기록 — 2026-11-10

계획: docs/superpowers/plans/2026-11-10-monologue.md

사용자의 계획 작성·구현 요청에 따라 기존 비 Git 작업 폴더에서 진행했다. 원본 프로그램 및 사용자 자료는 수정하지 않았다.

## 구현 완료 (v0.2 첫 지원 범위)
1. UTF-8/CP949/조합형/관찰된 Galmuri 소스 로더 및 제한된 include/define 전처리.
2. 소스 위치를 보존하는 문법 번역기와 자체 AST.
3. Worker 실행 엔진, 부분 송신·바이트 코드·패턴·시간·문자열·입력 기능.
4. 혼잣말 편집/번역/실행/일시정지/중지 UI와 연결·비밀 입력 연동.
5. 독립 코드 리뷰, 테스트, 별도 배포 패키지 및 사용 안내.

리뷰에서 지적된 헤더 버전 충돌, 매크로 확장 메모리 한도, 반복 중 배열 메모리 누적 계산, 출력 IPC 과부하를 수정하고 관련 테스트를 추가했다.

## 실제 실행한 검증
- 전체 자동 테스트: 30개 통과, 실패 0.
- TypeScript 검사 및 esbuild: 종료 코드 0.
- 기존 UI 회귀: TCP, CP949, 명령 순서, IME 조합, 비밀 입력 기록 통과.
- 개발용 및 배포용 실제 Electron UI: 번역/실행, CP949 송수신, 패턴 감지, 입력 참조, 일시정지/재개/중지, 편집 시 무효화, 오류 표시 통과.
- 고유 수집 소스 101개 정적 번역: 93개 성공, 8개 실패. 결과는 docs/research/monologue-compile-results.json.
- electron-builder Windows x64 패키지: release-v0.2/win-unpacked. npm 탐색 실패 후 빌더의 node_modules 직접 탐색으로 완료했다.
- 이야기 실행.cmd는 검증한 새 버전을 가리킨다. 기존 release 폴더는 보존했다.

## 남은 호환성 작업
원본과 지연·패턴 의미를 비교 실행하지 않았다. 10ms 및 첫 감지 보존 등은 문서화한 잠정 프로필이다. 번역 성공 93개를 실제 게임에서 검증하지 않았으며, 실제 서버에 자동사냥 명령을 보내지 않았다. SCF 실행 및 원본 SCF 생성은 이번 범위에 포함하지 않았다. 다음 단계는 주사용 SCS 선정 후 원본과 동작 비교, 실패 소스 8개의 개별 원인 확인이다.

# 혼잣말 v0.2 사용 안내

## 실행 순서
1. `release-v0.2/win-unpacked/Iyagi Mud.exe` 실행 후 **혼잣말**을 엽니다.
2. SCS 파일을 불러옵니다. UTF-8, CP949, 조합형, 관찰된 KSR 갈무리 문서 형식을 해독합니다. 인코딩이 잘못 보이면 명시적으로 선택해 다시 불러오세요.
3. 사용자 헤더가 필요하면 헤더 폴더를 선택합니다. 소스 폴더와 선택한 헤더 폴더 안에서만 찾습니다. 같은 이름의 내용이 다른 헤더가 있으면 오류를 내므로 사용할 버전을 명확히 정리하세요. I.H와 ENGLISH.H는 자체 호환 정의로 처리합니다.
4. **번역**으로 오류와 경고를 확인합니다. 편집하면 번역 결과가 무효화됩니다. 저장은 UTF-8로 하며 원본은 별도 이름으로 보관하는 것을 권합니다.
5. 서버에 연결하고 로그인한 후 **실행**합니다. 실행하면 게임 명령을 전송합니다. 먼저 `examples/monologue-demo.scs`의 단일 보기 명령으로 확인하세요.
6. **일시정지 / 재개 / 중지**, 또는 **모든 자동 전송 중지**를 사용합니다. 연결 해제와 비밀 입력 진입도 중지합니다. 이미 전송된 명령은 취소할 수 없습니다.

## 지원하는 첫 구현 범위
- 한국어/C식 변수·배열·함수·조건·반복·반환과 include/define 전처리.
- 보내기/정수보내기, 지연, 찾을글/찾은글번호/찾은글정리, 글마중 계열.
- 문자열 조작과 숫자 변환, 입력 대화상자, 로컬 출력, 날짜/시간, 갈무리 종료.
- 보내기는 부분 문자열을 보내며 `|`가 줄 끝입니다. 연속된 `|`도 보존합니다. `$$`, `$D`, `$T`, `$#0`~`$#255`를 지원합니다. 일반 입력창 매크로와 혼잣말 송신 문법은 다릅니다.
- 별도 Worker에서 실행하고 배열·문자열·호출 깊이·메모리·전송 및 출력 속도에 제한을 둡니다. 원본 프로그램의 직접 메모리/OS/파일 접근은 제공하지 않습니다.

## 잠정 호환 규칙과 제한
지연과 대기 시간 단위는 10ms입니다. 예: `지연(500)`은 5초입니다. 찾을글에서는 공백으로 패턴을 나누고 백틱을 패턴 내부 공백으로 해석합니다. 번호는 1부터 시작하며 첫 감지를 보존하고 찾은글정리로 초기화합니다. 이 규칙은 수집 소스를 근거로 정한 프로필이며 이야기멀티와 비교 실행으로 확정하지 않았습니다.

SCF 바이너리를 실행하거나 원본 SCF로 컴파일하지 않습니다. 자체 AST를 메모리에서 실행합니다. 문자열과 숫자, 화면 출력 등의 세부 동작이 원본과 다를 수 있습니다. 지원하지 않는 구문·함수는 오류로 알립니다. 사용자 정의 함수의 연속 호출 깊이는 128로 제한합니다.

## 검증 범위
고유 SCS 소스 101개를 정적으로 번역한 결과 93개 성공, 8개 실패했습니다. 실패에는 문자열 줄바꿈/따옴표 문제, 해독되지 않는 문자, 미지원 구문이 포함됩니다. 원본 자료는 수정하지 않았습니다. 결과 파일은 `docs/research/monologue-compile-results.json`입니다. 분석 도구는 자료 폴더의 상위 경로까지 헤더를 찾으므로 앱에서는 헤더 폴더를 직접 지정해야 할 수 있습니다.

번역 성공은 실제 게임 동작 호환성을 보장하지 않습니다. 모의 서버에서 한글 송수신·패턴 감지·입력 참조·일시정지·중지를 검증했으며, 수집된 자동사냥 소스를 실제 퇴마요새에서 실행하지 않았습니다. 다음 단계는 사용할 소스를 하나씩 선정해 원본과 이벤트·시간 동작을 비교하는 것입니다.

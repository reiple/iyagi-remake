## 확인한 사실

- README.TXT는 2001년 4월 이야기 멀티 for Windows 문서이며 CP949로 읽을 수 있다.
- IYAGI.EXE는 x86 PE32 실행 파일이다. 버전 리소스에는 MFC Application, 1.0.0.1로 표시된다. 이는 제품의 출시 버전을 확정하는 근거는 아니다.
- 실행 파일 문자열에서 WSOCK32.dll, telnet, iyghan.dll을 확인했다. 실제 프로토콜 동작은 아직 검증하지 않았다.
- SHA256: 480E2A4EE39936E71A6033F98C853DBCED4CD2B2F5DE1E9DA62EBFDD4AEDFBEC
- 도움말 IYAGI.HLP 및 iyagi.chm, 매크로 *.MAC, 자동반응 *.ANS, SCF 스크립트 디렉터리가 존재한다. 바이너리 설정 형식은 아직 해석하지 않았다.

## README에 명시된 호환 대상

- 이야기마당: 별도 입력 영역, | 구분 명령 순차 전송.
- 단축버튼 1~10: 사용자 지정 명령.
- 줄임글쇠: Alt+F1~F10 및 Shift+F1~F10, $A번호와 $S번호로 참조.
- $$: 리터럴 $ 전송.
- 자동반응: 문구 및 화면 좌표 조건, 글월 보내기, $, 전송 지연. 지연의 정확한 시간은 미확인.
- ALIAS.TXT: 최대 150줄 문장 추천. 명령 치환용 별칭과 구분해야 한다.
- 갈무리, 타이머, 자동반응 전체 실행/중지.
- F11 전체화면, F8 글꼴 설정.
- 혼잣말: 내장 번역기가 있는 스크립트 기능. 기존 언어 전체 호환은 별도 분석 필요.

## 신규 클라이언트 제안 (미확정)

Windows 데스크톱 앱으로 퇴마요새 xmud.ddnsfree.com:6666 접속을 기본 제공한다.
한글 인코딩 선택, Telnet 협상, ANSI 색상/커서 처리, 명령 기록, 단축버튼 및 매크로, 자동반응, 로그를 우선 구현한다.
CP949는 첫 후보이며 실제 서버 인코딩은 서버 응답으로 검증해야 한다.
기존 실행 파일 수정 대신 관찰된 동작을 독립 구현하는 방향을 권장한다.

# v0.2.1 채팅 입력 개선 — 2026-11-11

- 일반 화면 클릭 시 채팅 입력창에 포커스를 이동한다. 드래그/다중 클릭 텍스트 선택, 다른 입력 필드와 버튼, 열린 대화상자, 한글 조합 중에는 포커스를 강제로 이동하지 않는다.
- 환경 설정 → 화면·전송 → 채팅 입력창 위치에서 출력창 위/아래를 선택한다. 입력 영역(단축버튼 포함)을 DOM에서 이동해 화면과 키보드 탐색 순서를 맞춘다.
- 위치는 settings.json에 저장하며 기존 설정에 항목이 없으면 아래로 유지한다. 입력 중인 초안은 위치 변경 후에도 보존한다.
- 전체 자동 테스트 31개, 타입 검사/빌드 통과. scripts/chat-ui-test.mjs로 클릭 후 입력, 컨트롤/대화상자 포커스, 드래그 선택, 위/아래 배치, 초안 보존, 앱 재실행 후 위치 복원을 검증한다.
- 별도 배포 폴더 release-v0.2.1을 사용하며 기존 release 및 release-v0.2는 보존한다.

배포 파일의 새 채팅 UI 테스트와 혼잣말 UI 테스트, 개발 런타임의 기존 TCP/CP949/IME/비밀 입력 회귀 테스트도 통과했다. 이야기 실행.cmd를 검증한 v0.2.1 경로로 변경했다.

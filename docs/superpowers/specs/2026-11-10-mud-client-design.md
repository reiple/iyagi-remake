# 퇴마요새용 이야기 클라이언트 설계

날짜: 2026-11-10
상태: 사용자 검토용

## 목적
이야기멀티에 익숙한 사용자가 Windows에서 퇴마요새(xmud.ddnsfree.com:6666)를 편하게 플레이하는 독립 클라이언트를 만든다. 원본 실행 파일은 수정하지 않는다.

## 접근 방식
사용자는 독립 Windows 앱 제작을 선택했다. 원본 바이너리 수정은 오래된 의존성과 유지보수 부담으로 제외했다. 브라우저 전용 앱은 직접 TCP 연결이 불가능하여 별도 중계 서버가 필요하므로 선택하지 않았다.

## 구현 선택 (제작자 제안)
Electron, TypeScript와 xterm.js를 사용한다. 메인 프로세스가 TCP/Telnet 통신과 파일 저장을 담당하고 렌더러는 터미널 및 설정 UI를 제공한다. CP949 변환은 iconv-lite를 사용한다. 의존성 버전은 구현 때 공식 문서와 설치 가능한 버전을 확인한다. Windows 실행 및 배포용 패키지를 목표로 한다.

## 첫 버전의 화면과 기능
- 상단: 접속 프로필, 연결/해제, 인코딩, 설정, 로그 저장.
- 중앙: ANSI 색상과 커서 제어를 지원하는 터미널. 스크롤 기록과 선택 복사.
- 하단: 한글 IME를 지원하는 명령 입력창, 이전/다음 명령 탐색, 사용자 지정 단축버튼 10개.
- 설정: 글꼴/크기, 단축키, 매크로, 자동반응 규칙, 전송 간격.
- 퇴마요새 주소와 포트 기본 제공. 자동 로그인이나 비밀번호 저장은 첫 버전에 포함하지 않는다.
- 기본 인코딩 후보 CP949, UTF-8 선택 가능. 서버 초기 응답으로 실제 인코딩을 검증한다.

## 통신과 표시
Telnet 제어 바이트를 본문과 분리하고 ECHO, SUPPRESS-GO-AHEAD, TERMINAL-TYPE, NAWS 협상 중 구현 가능한 항목을 명시적으로 처리한다. 지원하지 않는 옵션은 거절한다. 분할 수신된 협상/문자 바이트를 유지하고 연결이 바뀌면 상태를 초기화한다. ANSI 스트림은 터미널 에뮬레이터에 전달한다. 서버의 화면 제어와 별개로 명령 입력창을 유지한다. 연결 시간 초과와 오류를 한국어로 표시하며 자동 재접속은 기본 비활성화한다.

## 이야기멀티 호환 범위
- | 구분 순차 명령, $$ 리터럴 $, $A1~$A10 및 $S1~$S10 매크로 참조.
- $, 지연: 원본 지연 시간은 미확인이므로 설정 가능한 지연 시간으로 제공하고 차이를 설명한다.
- Alt+F1~F10, Shift+F1~F10 매크로. OS와 충돌하는 키는 변경 가능하게 한다.
- F11 전체화면, F8 글꼴 설정.
- 문장 추천은 명령 치환 별칭과 구분한다. ALIAS.TXT 가져오기는 명시적 사용자 파일 선택을 통해 지원한다.
- 원본 .MAC/.ANS 바이너리 가져오기, 혼잣말 언어, 좌표 기반 자동반응은 첫 버전 범위 밖이다. 지원한다고 표시하지 않는다.

## 매크로 및 자동반응
명령 큐에서 전송 간격을 지킨다. 참조 순환과 과도한 확장을 차단하고 큐 길이를 제한한다. 연결 해제 시 큐와 타이머를 비운다. 즉시 중지 버튼을 제공한다.
자동반응은 색상 코드를 제외한 수신 텍스트에 대한 문자열 일치로 시작한다. 줄바꿈 없는 프롬프트도 감지하도록 제한된 최근 텍스트 버퍼를 사용한다. 규칙별 활성화와 재실행 대기 시간을 제공한다. 기본 비활성화하며 규칙 설정 후 사용자가 켠다. 정규식 및 복잡한 스크립트는 후속 범위다.

## 데이터와 보안 경계
프로필, 화면 설정, 매크로와 규칙은 사용자 데이터 디렉터리의 JSON에 저장한다. 로그는 사용자가 시작/종료하고 저장 경로를 선택한다. 입력 명령 기록은 세션 메모리에만 유지하며 비밀번호 입력 모드에서는 기록하지 않는다. 서버가 비밀번호 입력을 알려주지 않을 때를 위해 수동 비밀 입력 모드를 제공한다.
렌더러에는 Node 접근을 제공하지 않고 contextIsolation과 제한된 IPC를 사용한다. 서버 출력으로 로컬 파일/외부 URL 실행이 발생하지 않도록 한다. 원본 폴더의 개인 설정과 로그를 자동 복사하지 않는다.

## 검증과 완료 기준
로컬 모의 Telnet 서버로 협상 분할 수신, CP949 문자 분할 수신, IAC 이스케이프, 연결 해제/재연결을 검증한다. 매크로 순서·지연·순환 차단과 자동반응 중복 방지를 검사한다. 한글 조합 입력, ANSI 출력, 설정 저장, 로그 저장을 앱에서 확인한다. 실제 퇴마요새에는 초기 접속 화면까지 확인하며 계정 로그인은 사용자에게 맡긴다.
실행 가능한 앱 소스, 실행 안내, 빌드 결과와 검증 기록을 제공한다. 환경 제약으로 패키징 또는 실제 연결이 실패하면 해당 항목을 완료로 표시하지 않는다.

## 설계 검토 반영
첫 버전은 단일 접속 세션과 Windows x64 배포를 기본으로 한다. 독립 검토에서 구현 계획을 막는 미확정 사항은 발견되지 않았다. Telnet 협상 응답과 매크로 파싱의 세부 규칙은 구현 계획과 테스트에서 구체화한다.

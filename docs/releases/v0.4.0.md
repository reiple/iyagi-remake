# 이야기 MUD와 이야기 모노로그 0.4

0.4는 Windows 데스크톱 이야기 MUD와 브라우저에서 여러 캐릭터의 혼잣말을 관리하는 이야기 모노로그를 함께 배포합니다. GitHub 태그와 두 npm 패키지 버전은 `v0.4.0`과 `0.4.0`입니다.

## 데스크톱 설치와 업그레이드

1. [GitHub 릴리스](https://github.com/reiple/iyagi-remake/releases/tag/v0.4.0)에서 `Iyagi-Mud-0.4.0-win-x64.zip`과 `.sha256` 파일을 내려받습니다.
2. Windows x64에서 ZIP을 새 폴더에 모두 풀고 `Iyagi Mud.exe`를 실행합니다. 앱 이름 아래와 정보 창에 `v0.4`가 표시됩니다.
3. **접속 → 서버 연결**에서 프로필을 선택합니다. 이전 버전의 접속 프로필과 설정은 앱 폴더 밖의 기존 사용자 데이터 폴더에서 불러옵니다. [Windows 배포 안내](../distribution.md)

데스크톱에서 혼잣말 실행을 시작하면 편집 창이 닫히고, 불러온 파일명이 사이드바에 표시됩니다. 실행 요청이 실패하면 편집 창에서 오류를 확인할 수 있습니다.

## 모노로그 실행과 업그레이드

`v0.4.0` 태그의 소스를 내려받고 저장소 루트에서 Docker Compose를 실행합니다.

```powershell
docker compose -f web-monologue/compose.yaml up -d --build
```

[localhost:3000](http://localhost:3000/)에서 캐릭터를 선택합니다. Compose로 이미 운영 중이면 같은 프로젝트의 데이터 볼륨에 저장된 캐릭터, 암호화 키와 소스를 새 컨테이너에서 불러옵니다. 컨테이너를 교체하면 진행 중인 게임 연결과 혼잣말 실행이 종료되므로 다시 접속하고 실행합니다. [모노로그 사용 안내](../../web-monologue/README.md)

모노로그에서는 파일을 지정하고 저장하면 창이 닫힙니다. 캐릭터 목록에서 파일명과 실행 상태를 확인하고 혼잣말을 실행하거나 중지할 수 있습니다.

## 채팅과 출력

| 기능 | 사용 방법 |
| --- | --- |
| 재접속 | 연결이 끊긴 뒤 Enter를 두 번 누릅니다. 데스크톱은 직전 서버로, 모노로그는 텍스트 화면을 열어 둔 캐릭터로 연결합니다. |
| 명령 기록 | ↑·↓로 최근 20개를 찾습니다. 최신 항목 다음에서 입력창이 비워지고, ↑·Enter를 번갈아 눌러 같은 명령을 다시 보낼 수 있습니다. 비밀 입력은 기록에서 제외됩니다. |
| 이야기멀티 전경색 | `$#155=114F안녕하세요$#155=7F`를 보내면 서버가 돌려보낸 `안녕하세요`가 밝은 노란색으로 표시되고, 이어지는 글자는 기본색으로 돌아갑니다. 모노로그에서는 보낸 명령을 화면에 표시할 때도 이 색을 적용합니다. |

## 릴리스 검증

- 데스크톱 자동 테스트 39개와 모노로그 자동 테스트 19개가 통과했습니다. 두 앱의 TypeScript 검사도 통과했습니다.
- Windows x64 ZIP을 압축 해제해 `v0.4` 표시와 명령 기록, 재접속, ANSI 색상, 혼잣말 동작을 확인했습니다.
- Chrome과 로컬 모의 Telnet 서버로 모노로그의 채팅, 색상, 한글 입력, 비밀 입력과 혼잣말을 확인했습니다. 0.4.0 Docker 이미지를 빌드하고 컨테이너 재시작 후 테스트 캐릭터와 소스의 복구를 확인했습니다.
